# Changelog

All notable changes to Brasil Torrent will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/), and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-07-24

### Added
- Initial public release
- Full BitTorrent support (DHT, PEX, UPnP, magnet links, .torrent files)
- Accessible UI with full NVDA/JAWS/Narrator support
- Voice progress announcements via SAPI5 / accessible_output2
- System tray integration with accessible icon (Ctrl+Shift+B to restore)
- Keyboard shortcuts for all actions
- Bilingual interface (pt-BR / en-US) with auto-detection
- Start/Stop/Continue torrent management
- Speed limits, sequential download, auto-start with Windows
- Notifications for download completion
- Filter tabs: All / Downloading / Seeding / Paused / Finished
- Detailed torrent dialog with file tree and real-time stats
- Confirm exit dialog with minimize-to-tray option
- Session persistence across restarts
- Logging to file for debugging
- 105 automated tests
