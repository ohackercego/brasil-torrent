# Roadmap

## v1.0 — Current Release

- [x] Core BitTorrent functionality (DHT, PEX, UPnP, encryption)
- [x] Accessible UI with full screen reader support
- [x] Voice progress announcements
- [x] System tray with global hotkey restore
- [x] Keyboard shortcuts for all actions
- [x] Bilingual interface (pt-BR / en-US)
- [x] Start/Stop/Continue torrent management
- [x] Speed limits
- [x] Settings dialog with persistence
- [x] Confirm exit dialog
- [x] Logging and diagnostics

## v1.1 — Short-term

- [ ] Portable mode (no install required)
- [ ] RSS feed support for automatic downloads
- [ ] Queue management (prioritize torrents)
- [ ] Labels and categories
- [ ] Per-torrent speed limits
- [ ] Move completed downloads
- [ ] Improved UPnP/NAT-PMP support
- [ ] Bandwidth scheduler

## v1.2 — Medium-term

- [ ] Streaming mode (sequential download with video player integration)
- [ ] Embedded trackers view
- [ ] IP filtering (eMule DAT / PeerGuardian)
- [ ] Proxy/VPN support (SOCKS5, HTTP)
- [ ] Encryption settings per-torrent
- [ ] WebUI (remote management)
- [ ] Plugin system
- [ ] Swedish, German, French, Spanish translations

## v2.0 — Long-term

- [ ] Built-in media player
- [ ] Search engines integration
- [ ] Cross-platform (Linux, macOS)
- [ ] Dark mode / high contrast themes
- [ ] Auto-updater
- [ ] UPnP port mapping diagnostics
- [ ] SSR (Subtitle Support for accessibility)
- [ ] Community translation platform
