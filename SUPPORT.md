# Support

Welcome to Brasil Torrent support. We're here to help.

## 📖 Documentation

Before opening a support request, please check:

- [README.md](README.md) — Features, installation, keyboard shortcuts
- [FAQ.md](FAQ.md) — Frequently asked questions
- [CONTRIBUTING.md](CONTRIBUTING.md) — Development setup and contribution guide
- [SECURITY.md](SECURITY.md) — Vulnerability reporting

## 🐛 Bug Reports

Open an issue on [GitHub Issues](https://github.com/azurejoga/brasil-torrent/issues) with:

- Steps to reproduce
- Expected vs actual behavior
- Logs from `log.txt` or `data/brasil_torrent.log`
- Screen reader and version (if accessibility-related)

## 💬 Feature Requests

Open a [feature request](https://github.com/azurejoga/brasil-torrent/issues/new) describing:

- The problem you're trying to solve
- How the feature would work
- Why it's useful for the community

## 🔒 Security Issues

**Do not** open a public issue. See [SECURITY.md](SECURITY.md) for private reporting.

## ✅ Before Asking

- Make sure you're on the [latest version](https://github.com/azurejoga/brasil-torrent/releases)
- Restart the application
- Check if the issue is already reported
- Review the logs at `data/brasil_torrent.log`
